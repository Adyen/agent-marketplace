# Materialize Codex as a native harness with externally owned configuration entries

Codex support is a direct, opt-in harness target and source layout—not plugin packaging—that compiles, ingests, and converts every marketplace-selectable resource kind across the native `.agents` and `.codex` paths, honors `CODEX_HOME`, turns commands into skills, diagnoses unrepresentable fields, and leaves rules and `AGENTS.md` out of scope. Compilation and sync do not require a Codex executable; `.codex` is the source marker, current output formats are emitted, and deprecated prompts are accepted only as migration input. Because hooks and MCP servers share user-editable configuration, Agent Marketplace preserves unmanaged content and reconciles only externally recorded owned entries using raw-preserving target-specific patchers, mandatory backups, locking, fail-closed state, collision refusal, and explicit repair operations.
