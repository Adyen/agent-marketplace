# Separate telemetry level from telemetry authority and routing

Agent Marketplace treats telemetry level, authority, and destination as separate concerns: a user selects `off`, `basic`, or `detailed`; organization configuration may enforce a minimum and replace the primary endpoint; and diagnostic collection is a reviewed per-invocation overlay. A separately authorized community report may send only the basic schema to the project endpoint, using user authority when unmanaged and organization authority when managed, while detailed and diagnostic data stay on the primary route. This keeps managed telemetry enforceable and inspectable, permits explicit contribution of project-wide adoption data, prevents sensitive fan-out, and avoids duplicate export when both routes resolve to the project endpoint.
