## Why

Landing still uses dense cards, decorative gradients, and inconsistent type
roles that no longer match the public-site foundation.

## What Changes

- Apply the public-site type, spacing, color, and geometry roles to Landing.
- Replace decorative grids, glows, gradients, and shadows with flat surfaces.
- Preserve the existing section order, destinations, product content, and
  interactive behavior while improving responsive reflow.

## Capabilities

### Modified Capabilities

- `marketplace-web-ui`: Landing gains an explicit visual hierarchy built from
  the shared public-site foundation.

## Impact

The change affects Landing components and section styles. It does not change
routes, resource behavior, documentation content, or Marketplace application
presentation.
