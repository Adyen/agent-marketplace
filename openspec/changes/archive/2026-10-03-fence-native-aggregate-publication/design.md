## Decisions

Use the existing strict native snapshot with expected observed file identity for both merge input and marker inventory. Treat only genuine missing input as an empty aggregate; unsafe or generation errors remain refusals. Carry the real destination boundary from orchestration, then use the shared captured byte publisher preserving mode/private creation and validating destination/named-parent/staged authority. Do not change JSONC merge semantics, marker ownership, collision policy or supported user settings. Durable-ownership adapters and their journal/recovery authority are not closed by this marker-based lane. No arbitrary new thresholds, fsync additions or claim of excluding uncooperative writers.
