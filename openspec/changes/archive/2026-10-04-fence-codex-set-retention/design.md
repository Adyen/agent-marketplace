## Context

The set loader protects manifest payload reads but previously returns only claims after closing its directory. Retention then removes claimed archive names and the manifest by path. Opened regular-member state and the manifest generation authorizing those removals are lost.

## Decisions

Expose the existing loader beneath a caller-owned captured directory. Parsed manifests retain a private in-memory opened identity, omitted automatically by JSON encoding. Selected claims must match that manifest generation, selected archives must admit strict opened regular/single-link state, and every selected name is preflighted before mutation. Revalidate the manifest generation before every archive unlink, and unlink the manifest last. Reuse ordinary observed-member unlink without adding sync or retaining descriptors across the plan. Existing selection/filtering/order semantics and metadata format stay unchanged; no whole-plan transaction or writer exclusion. Directory preparation/remaining restore and ownership evidence remain open.
