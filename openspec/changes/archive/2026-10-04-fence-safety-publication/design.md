## Context

WriteSafetyBackup creates directories, payloads and atomic sidecar output by path. Metadata publication for real state/journal already uses captured descriptors and can serve sidecars once its existing mechanism receives the captured parent plus real validation callback.

## Decisions

Prepare canonical state namespaces via strict component opens and descriptor-relative Mkdir(0700), never following unsafe components or chmodding existing directories. Actual Apply and BackupOnly share preparation. Capture safety parent, verify after timestamp callback, exclusively create payload through CreateTemp(0600), sync and retain producer inode/full state. Refusal cleanup examines name through captured parent and removes only the original attempt inode, preserving replacements. Publish sidecar through shared captured metadata writer after checking named parent and payload state; public filenames/JSON/private permissions unchanged. Keep existing comments unchanged. Directory and payload/sidecar publication are not one overall transaction; post-publication errors and uncooperative writers are not excluded. Retention, CAS evidence cleanup and original-record/action leases remain separate.
