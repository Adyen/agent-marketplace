## Why

Marketplace operators need task-focused guides whose commands, configuration and expected results match the current service and governing specifications. The operator guides mix how-to steps with reference tables and explanation, and several commands lack expected results.

## What Changes

- Audit all ten guides under `site/docs/how-to/operator/` for competent Marketplace operators.
- Keep each guide in the how-to quadrant and link to reference or explanation for other needs.
- Verify commands, flags, configuration keys, paths, environment variables, endpoints, diagnostics and expected output against current source and specifications.
- Tighten prose, show exact or labelled typical results, and retain useful failure recovery.
- Restructure pages only when the audit justifies it, updating navigation and every inbound link.

## Capabilities

### New Capabilities

None. This change audits prose only.

### Modified Capabilities

None. Runtime behavior and normative requirements remain unchanged.

## Impact

The ten public operator guides and spec-less change artifacts. No runtime, test, normative-spec, screenshot or immutable documentation-snapshot changes. Other pages may receive required link fixes only.
