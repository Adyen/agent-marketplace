## Context

CreateCodexSet produces two partial archives, renames them to final names, then writes and renames a partial manifest. The old manifest os.WriteFile follows a pre-existing partial alias. Neither final publication nor cleanup retained producer generation authority.

## Decisions

Capture the existing set directory after current directory preparation. Use descriptor-relative Lstat for unused operation selection, treating existing final or partial manifests as occupied, including dangling aliases. Reuse the archive output producer beneath that captured parent instead of reopening its path for each archive. Producer FileInfo supplies the owned identity; later path classification cannot adopt a replacement. Partial manifest creation is exclusive0600 and changes to its existing0644 metadata mode after producing bytes. Member publication validates recorded state, regular/single-link shape, final-name absence and the named parent, then performs descriptor-relative rename. Record the new member name immediately so refusal cleanup remains authorized after a successful rename. Cleanup compares tracked object identity and never removes a replacement. Keep manifest-last completeness without adding fsync, new budgets or transaction claims. Namespace preparation and retention remain follow-ons.
