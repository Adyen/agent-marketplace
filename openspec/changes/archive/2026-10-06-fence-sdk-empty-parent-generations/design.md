## Decision

Use the SDK's existing captured output Dir and NativeRoot. For each discovery-admitted parent below the output root, capture its parent through no-follow OpenPath, match that descriptor's inode and captured child directory, revalidate the discovery-admitted ancestry at the meaningful cleanup boundary, then use shared descriptor-relative Rmdir (directory-only namespace removal). A scoped operation closes its parent each iteration and propagates meaningful close/inspection/refusal errors. Nonempty parents stop ordinary cleanup without hiding a close error. Root is never removed. Captured discovery ancestry is root-to-leaf; each upward iteration validates only its retained prefix, not the already removed child.

## Consumer verification

Public SDK sync uses a real nested stale payload; after actual stale removal and initial parent inspection, replace empty parent with independently created foreign directory. Parent old code deletes foreign directory/reports success (red). New code generation-refuses, preserves foreign directory inode/mode/mtime and output membership, original admitted now-empty parent retained, own staging cleaned. Restoring original parent and real stale payload produces actual healthy stale and empty-directory removal; foreign directory remains unchanged. Full SDK/materialize/macCLI, Linux parity/repeated races/spec/shellcheck, timed disk prune and all-file review required. This does not independently establish whole transaction or atomic uncooperative-writer exclusion; final quarantined-payload deletion/restoration/reporting and closure audit stay separate.
