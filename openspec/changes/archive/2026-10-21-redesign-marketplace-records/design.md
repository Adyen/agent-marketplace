## Context

Public record routes still use several panel and container treatments that do
not align with the shared browser foundations or the redesigned catalog.

## Decisions

Use one shared record container with the same maximum width and gutters as
Landing, Docs, and the Marketplace browse route. Keep identity first, followed
by installation and inspection content separated by restrained rules.

Preserve Mono for commands, digests, paths, and other technical values. Status
meaning remains owned by Marketplace semantic roles and visible text.

Apply the same record shell to loaded, loading, unavailable, empty, and error
states. Administration pages retain their existing operational structure.
