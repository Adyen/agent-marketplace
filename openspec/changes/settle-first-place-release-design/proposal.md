# Proposal

## Why
The first place release needs a single design for selection, consent, presentation and delivery sequencing before implementation can be approved.

## What Changes
Record the proposed first-release behavior and CLI, profile, import and approval shapes. Bound the six implementation briefs and distinguish readiness for approval from authorization to implement.

## Capabilities
None. This work changes no normative capability.

## Impact
Only the target-profile design and planning records change. No production behavior changes.
